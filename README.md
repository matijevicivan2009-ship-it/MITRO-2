# RoboControl 3.0

Napredni interaktivni 3D simulator robotske ruke za završni rad iz elektronike i robotike.

## Funkcije
- 3D robotska ruka i kamera (Three.js)
- Manual / Auto način rada
- Upravljanje bazom, ramenom, laktom i hvataljkom
- X / Y / Z koordinate i inverse kinematics
- Brzina kretanja i HOME položaj
- Teach pozicije i izvođenje spremljene sekvence
- Automatski Pick & Place program s virtualnim predmetom
- Virtualni senzor prisutnosti predmeta
- Statusi READY / MOVING / GRIPPING / STOPPED
- Emergency Stop
- Brojač ciklusa
- Telemetrijski graf X/Y/Z
- Ograničenja zglobova

## GitHub Pages
Uploadaj `index.html`, `style.css`, `app.js` i `README.md` u root repozitorija. U Settings → Pages odaberi Deploy from a branch, `main` i `/(root)`.

Three.js se učitava preko CDN-a, pa je za 3D prikaz potrebna internetska veza.
